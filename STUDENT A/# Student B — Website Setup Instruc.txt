# Student B — Website Setup Instructions

## 1. Install the required software

1. Download XAMPP from https://www.apachefriends.org/
2. Install XAMPP. The default installation path should be:
   `C:\xampp`
3. Install Git from https://git-scm.com/downloads (optional if you download the repository as a ZIP).
4. Open the XAMPP Control Panel.

## 2. Download the project from GitHub

### Option A: Download as ZIP

1. Open the project’s GitHub repository.
2. Click the green **Code** button.
3. Select **Download ZIP**.
4. Extract the downloaded ZIP file.

### Option B: Clone with Git

Open Command Prompt and run:

```cmd
cd C:\xampp\htdocs
git clone YOUR_GITHUB_REPOSITORY_URL deployment-demo
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with the actual repository URL.

## 3. Place the project in XAMPP

The project folder must be located at:

`C:\xampp\htdocs\deployment-demo`

Make sure the folder contains:

- `index.php`
- `db.php`
- `database.sql`
- `nginx.conf`
- `README.md`

If the downloaded ZIP contains an extra nested folder, move the project files so that `index.php` is directly inside `deployment-demo`.

## 4. Start Apache and MySQL

1. Open the XAMPP Control Panel.
2. Click **Start** next to Apache.
3. Click **Start** next to MySQL.
4. Confirm both services show as running.

## 5. Create and import the database

1. Open http://localhost/phpmyadmin
2. Click **New** in the left sidebar.
3. Enter the database name:
   `deployment_demo`
4. Choose `utf8mb4_general_ci` as the collation if prompted.
5. Click **Create**.
6. Click the new `deployment_demo` database.
7. Select the **Import** tab.
8. Click **Choose File** and select the project’s `database.sql`.
9. Click **Import** or **Go** at the bottom.
10. Confirm that the `students` table appears and contains the sample records.

## 6. Check the database connection

Open this file in VS Code or Notepad:

`C:\xampp\htdocs\deployment-demo\db.php`

The default XAMPP configuration should look like this:

```php
<?php
$host = "localhost";
$dbname = "deployment_demo";
$username = "root";
$password = "";

try {
    $conn = new PDO(
        "mysql:host=$host;dbname=$dbname;charset=utf8mb4",
        $username,
        $password
    );
    $conn->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
} catch (PDOException $e) {
    die("Database connection failed.");
}
?>
```

If MySQL uses a different username or password on your computer, update those values accordingly.

## 7. Run the website

Open this URL in your browser:

http://localhost/deployment-demo/

The page should display the student records from the database.

## 8. Optional: Run through Nginx

If you also want to test the reverse proxy:

1. Download the Windows ZIP version of Nginx from https://nginx.org/en/download.html
2. Extract it to a folder such as `C:\nginx`.
3. Copy the repository’s `nginx.conf` into Nginx’s `conf` folder, replacing the default configuration.
4. Open Command Prompt in the Nginx folder.
5. Test the configuration:

```cmd
nginx.exe -t
```

6. If the test succeeds, start Nginx:

```cmd
start nginx.exe
```

7. Open:

http://localhost:8080/deployment-demo/

Nginx listens on port 8080 and forwards requests to Apache on port 80.

## Troubleshooting

- **Apache won’t start:** Check whether another application is using port 80.
- **MySQL won’t start:** Check whether another MySQL service is using port 3306.
- **Database connection failed:** Check the database name, username, and password in `db.php`.
- **404 Not Found:** Confirm the project folder is inside `C:\xampp\htdocs` and that `index.php` is directly inside it.
- **Nginx won’t start:** Run `nginx.exe -t` and check whether port 8080 is already in use.

Do not upload private keys such as `server.key` to GitHub.
